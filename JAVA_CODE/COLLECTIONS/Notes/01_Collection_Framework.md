# Collection Framework:

### Why do we need Collection Framework?

- If we want to Store group of objects and the multiple data together we usually use Array's, but it is have some Limitations.

#### Limitation of ARRAY:

1. Before creating the array we need to know the size of array in advance.

2. We can only store homogenous in it.

3. Java does not provide much support to array's.

4. so, we need to write the complex code and logic which consume more time.

So, to overcome these arrya's limitations we have collections in java.


## Difference between Array's and Collection

### Array:
1. Array's are index collection of fixed no.of homogenous data elements.

2. Array is fixed in size.

3. Array can store primitive and non-primitive data.

4. Array can only store homogenous data in it.

5. Array uses indexing to iterating and retrival.

6. Array it's self a Data Structure created using memory.

7. Array's are faster

8. Before creating an array we need to know the size in advance.

9. Array introduced in JDK 1.0 version.

10. Array dont have much in build methods.

11. Array Consumes more memory.

---

## Collection:

1. Collection is group of individual object represented as a single unit.

2. Collection was introduced in JDK 1.2 version.

3. Collection is growable/resizable in nature.

4. Collection can only store non-primitive data.

5. Collectin can store both homogenous and hetrogenous.

6. Collection may and may not uses indexing it depends on the underline data structure.

7. Collection uses different underline data structure.

8. Collection uses less memory.

9. Collection is slower.

10. Collection is having build in methods for almost all operations.

11. In Collection we don;t need to know the size of it in advance.

---

## Collection Framework:

Collection Framework in java represents Architecture for Sorting, Arranging and Manipulating group of objects.

OR

Framework in Programming language is prebuild structure, in build libraries, tools and rules that helps developer to build application in faster and standarized way.

NOTE: In normal programming we control the execution of program but in framework the framework control the flow.

---
